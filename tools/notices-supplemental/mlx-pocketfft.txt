pocketfft - vendored inside mlx-swift

Source:  mlx-swift/Source/Cmlx/mlx/mlx/3rdparty/pocketfft.h

mlx includes this header from backend/cpu/fft.cpp and backend/metal/fft.cpp,
neither of which is excluded on macOS, so it is compiled into the binary. Its
license lives only in the header comment reproduced below.

mlx's own ACKNOWLEDGMENTS.md carries a PocketFFT section, and the generator
emits that file too - but it reproduces an older notice, naming only
"Copyright (C) 2010-2018 Max-Planck-Society". The BSD-3 terms require the
copyright notice of the code actually shipped, so the header of the vendored
copy is reproduced here in full, including the Peter Bell and odd-sized DCT-IV
copyrights that the acknowledgments text predates.
