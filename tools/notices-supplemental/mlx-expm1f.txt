expm1f - vendored inside mlx-swift

Source:  mlx-swift/Source/Cmlx/mlx/mlx/backend/metal/kernels/expm1f.h
         (mlx's own copy; upstream is Norbert Juffa's expm1f implementation)

mlx's Metal kernels include this file from unary_ops.h and erf.h, so it is
compiled into default.metallib and ships inside mlx-swift_Cmlx.bundle beside
the binary. Its license exists only as a comment at the top of that header -
no LICENSE file names it, and it is in no ACKNOWLEDGMENTS file - so the
generator cannot find it and the text is reproduced here in full. The BSD-2
